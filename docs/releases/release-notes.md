# Toonflow Custom 更新记录

### 2026-08-08

- 单条和批量视频生成都进入同一持久任务队列，页面请求结束后任务仍有明确状态，并限制同时生成数量，减少供应商拥堵。
- 同一镜头已有活动任务时会直接复用，客户端也可以用请求标识安全重试，避免重复生成。
- 应用异常退出后，尚未进入供应商调用的任务可以重新排队；可能已经产生费用的任务会停在“需人工确认”，避免自动重复扣费。
- 火山引擎视频生成现在会保存远端任务编号；应用重启、轮询网络暂时失败或本地保存失败时，会继续查询原任务，不重新产生视频生成请求。
- 其他尚未支持可恢复协议的供应商继续使用原有兼容路径，并保持“状态不明确时人工确认”的安全策略。
- 任务支持排队、等待重试、取消、失败和人工确认等可解释状态，现有任务和视频页面仍能读取兼容状态。
- 任务中心新增“持久任务”页签，自动刷新并展示任务通道、供应商远端编号、尝试次数和状态说明；用户可以按项目、通道和状态筛选任务。
- 支持从任务中心安全取消、重新入队和“确认供应商状态后重试”；危险操作会明确提示远端取消边界和重复扣费风险，原有历史任务保留在独立页签中。
- 新增项目指南、故障排查、功能目录和可生成索引的知识中心，并建立参考开源项目的增量扫描与吸收台账。
