# Toonflow Custom 更新记录

### 2026-08-08

- 单条和批量视频生成都进入同一持久任务队列，页面请求结束后任务仍有明确状态，并限制同时生成数量，减少供应商拥堵。
- 同一镜头已有活动任务时会直接复用，客户端也可以用请求标识安全重试，避免重复生成。
- 应用异常退出后，尚未进入供应商调用的任务可以重新排队；可能已经产生费用的任务会停在“需人工确认”，避免自动重复扣费。
- 火山引擎视频生成现在会保存远端任务编号；应用重启、轮询网络暂时失败或本地保存失败时，会继续查询原任务，不重新产生视频生成请求。
- 其他尚未支持可恢复协议的供应商继续使用原有兼容路径，并保持“状态不明确时人工确认”的安全策略。
- 任务支持排队、等待重试、取消、失败和人工确认等可解释状态，现有任务和视频页面仍能读取兼容状态。
- 任务中心新增“持久任务”页签，自动刷新并展示任务通道、供应商远端编号、尝试次数和状态说明；用户可以按项目、通道和状态筛选任务。
- 支持从任务中心安全取消、重新入队和“确认供应商状态后重试”；危险操作会明确提示远端取消边界和重复扣费风险，原有历史任务保留在独立页签中。
- 批量资产图与分镜图改为逐项进入持久队列，重复点击会复用活动任务，应用退出后按付费边界恢复或停在人工确认，不再由页面后台并发任务决定生命周期。
- 任务中心可维护供应商/模型/任务通道级限流规则，包括最大并发、每分钟请求数和冷却时间；未配置时采用保守默认值。
- OpenAI 标准供应商新增 GPT Image 文生图和可恢复异步视频能力，支持官方 Sora 视频流程；CLIProxyAPI 地址会自动使用其 OpenAI 视频兼容路由，也可手工指定视频地址。
- CLIProxyAPI 是否能实际生成视频取决于代理侧是否存在 xAI/OpenAI 视频凭据；仅出现文本和 GPT Image 模型时，视频适配器虽已就绪但无法完成真实提交。
- MiniMax 海螺视频生成拆分为提交与查询两个阶段，远端任务编号会立即保存；应用重启、轮询网络暂时失败或本地保存失败后继续查询原任务。
- MiniMax 当前未配置未经验证的远端取消接口；用户取消会阻止 Toonflow 继续处理，但供应商端任务仍可能继续产生结果或费用。
- 可灵文生、图生、多图参考和 Omni 视频任务会把“接口类型 + 远端任务编号”一起保存，应用重启后回到正确接口查询原任务。
- 可灵恢复查询只接受模板中预定义的视频接口路径，数据库中的任务身份不能改造成任意请求地址；当前同样只提供本地取消边界。
- 项目顶部新增“配音与字幕”入口：可从剧本导入角色对白、旁白和群声，按角色分配音色，并对单句内容进行编辑、锁定和重新生成。
- 逐句配音进入持久音频队列，批量操作会先检查所有台词是否已有音色，避免执行到一半才发现缺失配置；任务状态也可在持久任务中心查看。
- 字幕可按句校准开始/结束时间并锁定人工修改，重建时不会覆盖锁定内容，可直接导出 SRT 或 WebVTT。
- OpenAI 标准供应商已接通 GPT-4o mini TTS、TTS-1 和 TTS-1 HD；角色音色表会列出可用模型和内置音色，也允许填写符合供应商契约的自定义 voice ID。
- OpenAI TTS 支持语速，并把情绪、音高和音量目标作为 GPT-4o mini TTS 的声音指令；页面明确提示生成语音由 AI 合成而非真人录音。其他仍为空实现的供应商会明确失败。
- 逐句配音成功后会优先使用本地 ffprobe 读取真实音频时长，自动重建未锁定的字幕 cue；没有 ffprobe 时保留安全估算，不让配音任务因此失败。
- “配音与字幕”新增规范化时间线标签，可生成带版本和输入校验和的结构化时间线；视频、视频原生声音、对白、旁白、SFX、环境声、BGM 与字幕独立成轨，并提示缺失选片或超时内容。当前构建时间线不会立即渲染成片。
- 规范化时间线现在可以提交低清预览或高清成片：多个候选视频会按时间线裁剪、统一横屏或竖屏尺寸并串联合成为 H.264/AAC MP4；可维护音效、环境声和背景音乐，混入视频原声、逐句对白与旁白，并在对白出现时自动压低背景。成片执行两遍响度/true peak 标准化并烧录安全区字幕；缺失音轨会安全跳过。渲染进入持久任务，页面可查看状态、播放或下载结果，相同版本可安全复用已有文件。
- 成片后可运行本地持久媒体 QA，自动检查编码、分辨率、帧率、时长、黑帧、冻结帧、静音、综合响度、true peak、字幕阅读速度、安全区容量和时间线警告；报告在页面显示错误、警告及对应时间点，不调用云端分析模型。
- 任务中心新增项目预算与模型价格配置：价格由用户按供应商账单维护，已知价格会在视频、图片和逐句配音入队前预留预算并阻止超额；可选择阻止没有价格规则的任务，系统不会猜测价格。成片卡支持记录“审核通过”或“退回修改”及审核意见，记录绑定成片校验和。
- 登录密码改用本机 scrypt 加盐哈希，新安装首次登录必须修改公开默认密码，旧明文密码会在成功登录后自动迁移；用户信息接口不再返回密码。服务默认只监听 127.0.0.1，任务中心可导出不含密钥、项目名称、剧本和生成内容的脱敏诊断报告。
- 新增项目指南、故障排查、功能目录和可生成索引的知识中心，并建立参考开源项目的增量扫描与吸收台账。
