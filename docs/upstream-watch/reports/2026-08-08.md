## 自动吸收

ArcReel 持久任务可靠性（评分 88/100）：以 TypeScript/Knex 独立重写持久任务表、lease、有限并发、活动资源去重、请求幂等、取消、退避、重启恢复和未知供应商状态保护。落点为 `src/services/task-engine/`，首个接入点是批量视频生成。

Toonflow 落地提交：`9282f95`。

第一批的关键安全决策：当时 Toonflow vendor API 不暴露 submit/poll 边界和 provider job ID；任务一旦进入供应商调用，异常或重启进入 `manual_review`，不得自动二次提交。第二批开始对明确支持的供应商缩小这一限制。

### 第二批：供应商 job ID 恢复

继续吸收 ArcReel 的远端任务身份锁定原则，建立可选 `videoSubmit/videoPoll/videoCancel` 契约，并让普通火山引擎成为首个实现。job ID 落库后，应用重启或轮询失败会继续查询原任务。保留旧 `videoRequest`，其他供应商不受破坏。

本批只用本地 Mock 验证提交/查询协议，没有访问真实火山引擎或产生费用。Toonflow 落地提交：`d5eca2c`。

### 第三批：统一视频生成入口

把制作工作台的单条视频生成迁入与批量生成相同的 `video.generate` 持久任务；保持前端仍收到原 `videoId`。至此视频工作台两个正式入口共享去重、有限并发、重试、恢复和火山 job ID 续跑能力。Toonflow 落地提交：`3551338`。

### 第四批：Toonflow-web 可维护源码

把 Toonflow-web `9c4cb0e` 以 squash subtree 纳入 `frontend/`，保留明确的下一次扫描游标和上游同步方式。根构建现在会先构建 Vue 前端、安全替换 `data/web`，再构建后端/Electron；开发者可直接维护无限画布、任务页面和设置页面源码。

首次独立构建中只做兼容修复，不复制其他参考项目代码，也不改变后端接口。Toonflow 落地提交：`a631d1fc`、`eee77980`。

### 第五批：持久任务中心

把持久任务的可解释状态和安全操作接入原任务中心：默认页签读取新任务事实源并自动刷新，支持筛选、取消、普通重试和供应商状态人工确认后的重试；旧任务表保留为历史页签。界面延续 ArcReel 调研中“任务状态透明、人工介入点明确”的产品原则，但基于 Toonflow 现有 Vue/TDesign 页面独立实现。

Toonflow 落地提交：`b4bec68d`。

### 第六批：CLIProxyAPI/OpenAI 兼容供应商

本机 CLIProxyAPI 只读模型探测返回文本/Codex 与 GPT Image 模型，没有视频模型；通过必定在本地校验阶段拒绝的无效模型请求，确认 `/openai/v1/videos` 和原生 `/v1/videos` 路由存在，未提交任何真实生成。结合 v7.2.120 源码确认 Sora 兼容路由会转到 xAI 视频执行器，并支持创建、查询和鉴权下载。

基于官方 OpenAI Videos API 契约和上述本地路由，独立实现 OpenAI 供应商 2.2：GPT Image 文生图、Sora/CLIProxyAPI 异步提交、job ID 恢复、首帧图片和结果下载。当前代理没有视频凭据，因此只完成本地 Mock 验证。Toonflow 落地提交：`c4a5c5a0`。

登记后继续扫描到 v7.2.123：新增提交集中在凭据冷却、Codex/Gemini 大请求、兼容 thinking 和文档配置；OpenAI 图片/视频 handler 与路由无变化，本轮不追加吸收。下一次从 `31a4e9b4` 之后继续。

### 第七批：持久图片与供应商限流

把批量资产图和分镜图从响应后的页面级并发 Promise 改为逐项 SQLite 持久任务；沿用 ArcReel 调研中的资源去重、lease、付费边界和人工确认原则。`provider_limits` 正式接入 worker，并在任务中心提供供应商/模型/通道级并发、RPM 和冷却时间配置。Toonflow 落地提交：`c4a5c5a0`，限流表行标识修订：`1c0f9c11`。

### 第八批：MiniMax 远端任务恢复

沿用 ArcReel 的远端身份锁定原则，把 Toonflow 现有 MiniMax 海螺提交、查询、文件下载流程拆成可恢复 adapter。远端 task ID 持久化后，重启和轮询故障不重新提交；没有确证的远端取消 API 时保持本地取消边界。Toonflow 落地提交：`6acff39d`。

### 第九批：可灵多路径远端任务恢复

将可灵文生、图生、多图和 Omni 四类提交/查询路径拆成可恢复 adapter。持久身份保存白名单路径与 task ID，既能在重启后选择正确查询接口，也阻止任务数据变成任意请求路径。未确认远端取消 API 时继续使用本地取消边界。Toonflow 落地提交：`550ce044`。

### 第十批：角色音色、逐句台词与字幕 cue 底座

参考 huobao-drama `eb117853` 的产品流程，在 Toonflow 中独立实现角色音色表、逐句台词、字幕 cue、确定性剧本解析、角色资产匹配、锁定保护、SRT/VTT 导出和 `audio` 通道持久任务。没有复制该无许可证仓库源码，也没有沿用整轨替换视频原声的合成方式。

复核 Toonflow 现有供应商后确认，火山、MiniMax、OpenAI 等模板的 `ttsRequest` 目前都只是空占位。因此本批只落不产生费用的领域底座和任务边界，并让空结果/异常明确失败；真实 TTS 供应商与页面入口列入紧接着的实施批次。Toonflow 落地提交：`f6f5b0eb`。
