# 操作流程

## 小说/剧本到动态镜头

1. 在项目页创建项目并选择画风、画幅和模型。
2. 在小说/剧本入口导入内容，使用剧本 Agent 形成分集和剧本。
3. 提取角色、场景、道具；审核描述与提示词后批量生成资产图，或在单个资产中重新生成，每张图都独立进入持久队列。
4. 生产 Agent 根据导演 Skill 生成导演规划、分镜表和分镜图；批量分镜图和图片编辑画布中的生成节点同样进入持久队列。已保存画布会保留任务编号并在重开后恢复轮询。
5. 在制作工作台检查每条视频提示词和引用图，然后单条或批量生成视频。
6. 两种请求都进入 `generation_tasks`；刷新页面或重启不会丢掉“尚未付费提交”的排队任务。
7. 从左侧任务中心查看视频和图片持久任务；普通失败可重新入队，“需人工确认”必须先核对供应商后台再确认重试。供应商限流入口可调整并发、RPM 和冷却时间。
8. 在视频候选中选片，再进入“配音与字幕 → 规范化时间线”；需要音效、环境声或 BGM 时先打开“声音素材”加入资产并设置时间/增益，然后构建新版本。
9. 检查片段和警告后生成低清预览；确认镜头、声音和字幕后再生成高清成片。本地任务可在页面或任务中心的 `compose` 通道查看，完成后直接播放或下载 MP4。
10. 对候选成片运行“媒体 QA”；先处理报告中的错误，再评估警告。更换镜头或修改声音/字幕后需构建新时间线、重新渲染和运行新报告。
11. 在任务中心按供应商账单配置价格和项目预算；确认 QA 后在成片卡记录“审核通过”或“退回修改”。重新渲染后重新执行 QA 和审核。

## 逐句配音与字幕

1. 先在资产中心上传可用的音色/参考音频，再从项目顶部进入“配音与字幕”。
2. 选择剧本并导入台词；系统按“角色：台词”、旁白和群声确定性拆句，可选择同时扫描分镜描述。
3. 打开“角色音色”，把角色资产、供应商、TTS 模型和 voice ID 绑定；旁白可使用独立或项目默认音色。
4. 检查台词和自动匹配结果，必要时编辑并锁定人工内容；锁定台词不会被下次导入覆盖。
5. 使用 OpenAI 标准供应商时，可从下拉框选择 GPT-4o mini TTS/TTS-1 系列及内置音色；选择一条或多条台词进入持久配音队列，从任务中心查看 `audio` 通道状态。其他空 TTS 供应商会明确失败。
6. 在“字幕 cue”校准毫秒时间并锁定人工调整；重建只替换未锁定 cue，最后导出 SRT 或 WebVTT。

## 从 AI Novel 导入成品

1. 在 AI Novel Writing Assistant 导出整本小说 JSON，或导出成品短剧项目 JSON；也可以保持其本机服务运行并复制 Novel ID / Drama Project ID。
2. 打开 Toonflow 项目的“剧本”，点击“导入 AI Novel 成品”，选择粘贴、JSON 文件或本机 API；API 默认使用 `http://127.0.0.1:3000`。
3. 点击“仅校验并预览”，核对作品、角色、章节顺序、空正文警告和每集的新增/更新/无变化动作。来源未提供的结构化场次、对白和道具会明确显示为不可识别。
4. 勾选要作为 Toonflow 分集剧本的章节并确认导入。重复导入相同版本安全复用；新版本只更新同一外部章节映射的剧本。
5. 角色不会自动变成资产；确认剧本后选中分集并运行“提取资产”，再人工审核角色、场景和道具。

## 同步外部能力

运行 `yarn upstream:check` 和 `yarn upstream:scan` 只产生增量证据。由 Codex 按 `docs/upstream-watch/README.md` 评估、重写、验证并更新游标，参考仓库不会直接 merge 到 Toonflow。
