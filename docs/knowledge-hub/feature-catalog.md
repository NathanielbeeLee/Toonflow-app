# 功能目录

## Toonflow 原有亮点

### 双 Agent 分工

剧本 Agent 负责理解原文、故事骨架、改编策略和剧本；生产 Agent 负责资产衍生、导演规划、分镜和生产监督。高级模式可为各环节选择不同模型。

### 导演 Skill 与题材知识

仓库内的导演/题材 Skill 把叙事节奏、镜头语言和特定题材经验固化为可编辑知识，不只是一次性的通用提示词。

### 资产一致性与多参考视频

角色、场景、道具资产可复用并关联分镜；视频模型支持首帧、首尾帧、多图/音视频参考等不同模式，提示词按模型模板编译。

### 无限画布式生产工作台

这里的“无限”指空间式界面，不是无限生成、无限存储或真正没有性能边界。制作页面把剧本、导演计划、资产、分镜表、分镜和视频工作台做成可拖动节点；画布可缩放和平移，节点之间的连线表达生产顺序。

实际操作时可以拖动节点重新排布，空格加鼠标左键平移，滚轮按设置执行缩放或滚动，并可用自动布局恢复清晰排列。它的价值是让长流程仍能一眼看见上下游，同时允许在分镜、轨道和候选视频之间审核、替换、重生成，保留人工导演权，而不是黑盒一键出片。

当前前端源码位于 `frontend/`，发布运行的是构建同步到 `data/web/` 的产物。

## 自定义新增：持久视频任务

单条和批量视频生成都会先落 SQLite，再由有限并发 worker 执行。它解决应用退出丢任务、重复点击重复占用、无限并发冲击供应商的问题。任务提供排队、执行、等待重试、取消、人工确认和终态。

普通火山引擎进一步支持远端任务编号恢复：应用重启或轮询临时失败后继续查询原视频任务，不重复付费提交。其他供应商在完成同一 adapter 契约前仍走人工确认保护。

批量资产图、单张角色/场景/道具图、批量分镜图和图片编辑画布的生成节点都会逐项进入同一任务引擎；应用退出后，尚未调用供应商的任务安全重排，已越过付费边界但没有远端编号的任务停在人工确认。任务中心的“供应商限流”可按供应商、模型和通道设置并发、RPM 与冷却时间。图片画布会保存节点的任务编号，重新打开已保存画布时可恢复结果轮询。

### 持久任务中心

从左侧“任务中心”进入后，默认“持久任务”页签会每 5 秒刷新，可按项目、通道和状态筛选。列表显示供应商远端任务编号、尝试次数、错误/恢复说明，并提供取消和重新入队。

“需人工确认”表示系统无法证明供应商端是否已经接单；必须先到供应商后台核对，再使用“确认后重试”，否则可能重复扣费。旧图片、文本等尚未迁入持久引擎的记录仍可在“历史任务”页签查看。

## 自定义新增：逐句配音与字幕

剧本可以按“角色：台词”“角色: 台词”、旁白和群声标签拆成独立台词，并按角色资产名称自动匹配。每句台词都能单独绑定音色、编辑、锁定和进入持久音频任务；文本或音色参数没有变化时可复用相同缓存身份。

字幕不再只是生成后临时拼接的文本，而是独立 cue：可以保存毫秒级开始/结束时间、锁定人工调整，并输出 SRT 或 WebVTT。在项目顶部进入“配音与字幕”即可操作；OpenAI 标准供应商可生成真实逐句音频，其他空结果不会被标记为成功。

### 规范化时间线

“配音与字幕 → 规范化时间线”会把已选视频、视频原生声音、对白、旁白、SFX、环境声、BGM 和字幕组织成独立轨道，并保存可复现版本与输入校验和。页面会提示未选视频或字幕超出成片时长。

构建时间线后可点“生成低清预览”或“生成高清成片”。任务由本地 FFmpeg 持久渲染，不调用付费供应商；多个镜头按各自入点和时长裁剪，低清横屏为 854×480、竖屏为 480×854，高清使用项目 1080p 画幅，不同比例用黑边补齐而不拉伸，最后输出可播放/下载的 H.264/AAC MP4。相同时间线版本和 preset 已有完整文件时会直接复用。

“声音素材”可把资产中心的音频加入 SFX、环境声或 BGM 轨，并设置时间、入点、时长、增益和淡入淡出。渲染保留视频原声，按 cue 混入逐句对白和旁白；对白出现时自动压低其他背景总线。所有输入统一为 48kHz 立体声，经过两遍 -16 LUFS / -1.5 dBTP 母带标准化，并把字幕 cue 通过跨平台透明图层烧录到安全区。源视频无音轨、配音文件缺失或不可读时会记录跳过原因，仍安全完成其他轨道。

### 成片媒体 QA

完成低清或高清成片后可点“运行媒体 QA”。检查作为 `qa` 通道持久任务执行，覆盖文件/编码/尺寸/fps/时长、黑帧、冻结帧、静音、综合响度、true peak、字幕阅读速度与安全区容量，以及时间线本身的缺失/超时警告。页面显示错误、警告和对应时间点；阻断问题不会被“任务执行成功”掩盖。QA 只用本机 FFmpeg/ffprobe，不上传私人视频。

### 预算与人工审核

任务中心“预算与价格”允许为项目设置预算上限，并按供应商、模型、任务通道配置每请求/每秒/每字符价格。系统不会内置或猜测易变化的供应商价格；配置命中时在入队前预留预算并保存价格快照，超额会在付费提交前拒绝。可选择严格阻止所有未知价格任务，默认不阻断。

成片卡可记录审核通过或退回修改及意见。审核绑定当前 MP4 的输出校验和；重新渲染得到不同文件后必须重新审核，避免旧批准覆盖新内容。
