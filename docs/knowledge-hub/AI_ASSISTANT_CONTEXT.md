# AI 接手速读

1. 读根目录 `AGENTS.md`、`IMPLEMENTATION_PROGRESS.md` 和本知识中心 README。
2. 回答功能问题时先查 `feature-catalog.md` / `workflows.md`，再核对 `knowledge-map.yaml` 指向的当前源码。
3. 涉及参考项目更新时读 `docs/upstream-watch/sources.yaml` 与最新 report；只从游标之后增量扫描。
4. 修改业务功能时同步更新知识节点、专题文档、实施进度和上游吸收记录。
5. 用用户看到的页面名称和状态讲解；必要时再补 API、表和源码路径。

当前真实边界：持久任务已接入剧本资产提取、单条/批量视频、批量/单张资产图、批量分镜图、图片编辑画布生成、逐句 TTS、本地 FFmpeg 成片、媒体 QA 和发布交付包；视频提交前会执行提示词、参考素材、模型/供应商、时长分辨率和活动任务准备度门禁；普通火山引擎、OpenAI 标准接口、MiniMax 海螺和可灵视频支持远端任务续跑。分镜支持 Agent 生成动作拍点候选、前端编辑和人工确认，只有已确认拍点进入视频提示词；旧数据保持原路径。视频保存后本地异步生成海报帧，失败不影响视频成功，历史列表按需补齐。剧本页可从 AI Novel 的小说或短剧 JSON 预览并版本化幂等导入，角色只预览、不自动合并资产；常规资产提取只写当前项目/批次并确定性复用唯一近名角色/道具。“配音与字幕”支持角色音色、台词、字幕、声音素材、规范化时间线、六轨高清/低清成片、QA、成片审核和审核版本独立 ZIP；新审核会撤销旧包。价格只能来自用户规则，usage ledger 是预估预留而非供应商实际账单。账号使用 scrypt，默认密码首次登录强制修改，服务默认只监听 127.0.0.1，诊断导出不含秘密或业务内容。`manual_review` 是状态不明时防重复付费的安全停点，本地 FFmpeg/QA/发布打包不使用该付费边界。`data/web` 只能由 `frontend/` 构建同步。
