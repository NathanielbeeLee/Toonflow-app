# 故障排查

## 任务一直是“排队中”

确认应用服务仍在运行；打开“任务中心 → 持久任务”，查看任务的状态说明。如果所有任务都排队，检查控制台是否有数据库迁移或 worker 调度错误。不要通过重复点击绕过队列。

## 任务显示“需人工确认”

这表示应用在可能已经提交付费请求后失去确定状态。先登录对应供应商后台，用时间、模型和镜头定位远端任务：

- 远端仍在运行：等待或在供应商侧取消，不要重试 Toonflow。
- 远端成功：先下载/登记结果，当前首版还没有通用“认领远端结果”入口。
- 确认远端不存在或已取消：在任务中心点击“确认后重试”。该操作等价于显式确认未知供应商状态，可能重新产生费用。

## 重启会不会重复扣费

`claimed`（尚未进入供应商调用）的过期任务会安全重排。普通火山引擎、OpenAI 标准接口、MiniMax 和可灵在 `submitted/polling/finalizing` 状态已有远端任务身份时，会恢复查询原任务，不重新提交。`submitting` 阶段尚未写入任务身份，或供应商没有恢复协议时，仍进入人工确认。

## 批量生成重复点击

视频按项目、剧本和轨道去重；资产图、分镜图按各自实体 ID 去重。存在活动任务时会返回已有任务；客户端也可在请求中传稳定 `requestId`，网络重试将命中同一个幂等任务。

## CLIProxyAPI 看不到视频模型

模型列表没有 Sora/Grok 视频时，不代表路由不存在，但通常表示代理侧没有可用的视频凭据。先完成 CLIProxyAPI 的 xAI 登录或配置支持 OpenAI Videos API 的上游，再进行真实生成；不要用文本/Codex 凭据反复重试视频。Toonflow 可先配置 OpenAI 供应商的普通请求地址，CLIProxyAPI 本机端口会自动切换视频路径。
